# เอกสารส่งมอบสำหรับนักพัฒนา (Developer Handoff)
ระบบรับสมัครทุนการศึกษาออนไลน์ — มูลนิธิทิสโก้ เพื่อการกุศล · ฉบับ 1.0 (11 พ.ย. 2569)

> **สำคัญ:** โฟลเดอร์ `app/` เป็น **ต้นแบบ (prototype)** สำหรับดูหน้าจอและลำดับการทำงานเท่านั้น
> ข้อมูลเก็บในเบราว์เซอร์ (localStorage) · ไม่มีฐานข้อมูลจริง · ไม่ส่งอีเมลจริง · ไม่มีระบบความปลอดภัยจริง
> ระบบจริงต้องพัฒนาส่วนหลังบ้าน (API + ฐานข้อมูล + ที่เก็บไฟล์ + อีเมล) ใหม่ทั้งหมด

## 2. เปิดต้นแบบบนเครื่อง

```bash
cd app
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## 4. กฎสำคัญที่ต้องทำให้ถูก (รายละเอียดใน requirements.xlsx)

1. **ผลการพิจารณาเป็นความลับ** — นักเรียนและครูไม่เห็นผล ประกาศรายชื่อที่เว็บไซต์เท่านั้น
2. **อัตราทุนคิดจากระดับชั้นถัดไปที่สมัคร** + ประเภทวิชา ปวส. + อัตราพิเศษ ม.ต้นตามโรงเรียน
3. **เกรดเฉลี่ยต่ำกว่า 1.50** ส่งได้ แต่ติดป้าย “ไม่เข้าเกณฑ์” ให้ จนท.
4. **ใบสมัครที่แจ้งย้าย** จนท. รีวิวได้หลังหลักฐานการย้าย “ยืนยันสำเร็จ” เท่านั้น
5. **หลักฐานการย้าย** แก้ได้จนกว่า จนท. ยืนยัน · ยืนยันแล้วล็อก · เปิดสิทธิ์ใหม่โดย จนท. (นับวันทำการ) · หมดเขต 31 ก.ค. · รอบนับจากวันส่งครั้งแรก
6. **ยอดเงินเปลี่ยนจากการย้าย** ต้องให้แอดมินยืนยัน (ยอดเดิม/ใหม่) ก่อนผู้จัดการพิจารณา
7. **ปีที่ย้าย ครูโรงเรียนเดิมยังดูแลนักเรียน** (ต้นแบบใช้ฟิลด์ `home_school`) · ครูโรงเรียนใหม่ยังไม่เห็น
8. **1 สถานศึกษา = 1 บัญชีครู** · ครูคนใหม่แทนคนเดิม → ปิดบัญชีเดิม ใช้ Username เดิม
9. **จนท. / ผู้จัดการ** ไม่แบ่งงาน ใครหยิบใบไหนก็ได้ (1 ใบ 1 คน) · แก้ข้อมูลหลังบ้านได้ทุกช่องพร้อม Audit log
10. **ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์** ทุกคำขอ (ต้นแบบแค่ซ่อนปุ่ม)

## 6. ไฟล์และที่เก็บ

```
TF2570/TF2570-000009/TF2570-000009_01_IDCARD.pdf            ← เอกสารใบสมัคร
TF2570/TF2570-000009/TF2570-000009_14_TRANSFER_1-2.jpg      ← หลักฐานย้าย ครั้งที่ 1 ไฟล์ที่ 2
TEACHER_REG/2570/REG-0001_SCH-001_IDPROOF.pdf               ← หลักฐานครู (แยกจากนักเรียน)
```
- ไฟล์ถูกย้ายจาก server ไปเครื่องกลางของมูลนิธิฯ ทุกชั่วโมง (มีโปรแกรมอยู่แล้ว) → ระบบเปิดดู: หาใน server ก่อน → ไม่พบ เปิดจากเครื่องกลาง
- เครื่องกลางต้องมีตัวแจกไฟล์ผ่าน **HTTPS** + ตรวจสิทธิ์ผู้เปิด · เปิดได้ทั้งในออฟฟิศและที่บ้าน
- แปลง HEIC → JPG และย่อรูปตอนอัปโหลด · ไฟล์ละ ≤ 10 MB
