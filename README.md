# ระบบทุนการศึกษา มูลนิธิทิสโก้ เพื่อการกุศล

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `app/` | ต้นแบบที่ใช้งานได้ รวม 3 บทบาท (นักเรียน / ครู / เจ้าหน้าที่) ใช้ชุดรูปแบบเดียวกัน รองรับคอมพิวเตอร์และมือถือ |
| `db/` | ฐานข้อมูลกลาง (`schema.sql`), ข้อมูลพื้นที่ (`seed_geography.sql`), ข้อมูลจำลอง (`seed_mock.sql`) |
| `docs/` | เอกสารออกแบบฐานข้อมูล |
| `prototypes/` | ต้นแบบ HTML รุ่นเดิม (v28, Admin v14) เก็บไว้อ้างอิง |

## เปิด `app/` บนเครื่อง

หน้าเว็บโหลดข้อมูลจาก `app/data/` จึงต้องเปิดผ่านเว็บเซิร์ฟเวอร์:

```
python3 app/build_data.py              # สร้าง app/data/ ใหม่ เมื่อข้อมูลใน db/ เปลี่ยน
cd app && python3 -m http.server 8000  # แล้วเปิด http://localhost:8000
```

บัญชีทดลอง: ครู `t001`–`t100`, เจ้าหน้าที่ `reviewer01` `manager01` `admin01` รหัสผ่าน `Demo@1234`
